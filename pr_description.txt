💡 What:
`AuthField` コンポーネントのラベル内に、必須入力を示す視覚的なマーク（赤色の `*`）を追加しました。

🎯 Why:
ユーザーは入力フォームにおいて、どの項目が必須であるか直感的に把握できる必要があります。以前は `required` 属性のみが設定されており、視覚的なインジケーターが欠けていたため、UX の観点から改善を行いました。

📸 Before/After:
*   **Before:** ラベルのみが表示されていました（例: `メールアドレス`）
*   **After:** ラベルの横に赤いアスタリスクが表示されます（例: `メールアドレス *`）

♿ Accessibility:
追加した `*` 要素には `aria-hidden="true"` を設定しています。これにより、スクリーンリーダーが不必要に「アスタリスク」や「星印」と読み上げるのを防ぎ、標準の `required` HTML/ARIA 属性によって正しく必須項目であることが伝わるように配慮しています。
また、視覚的なマークを追加したことで React Testing Library の `getByLabelText` が文字列完全一致で失敗するようになったため、各テストファイル (`AuthField.test.tsx`, `AdminLogin.test.tsx`, `Onboarding.test.tsx`) にて、正規表現と `{ selector: 'input' }` を用いる堅牢なクエリに修正しました。
