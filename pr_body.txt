🛡️ Sentinel: [HIGH] Fix Admin Login Rate Limiting

🚨 Severity: HIGH
💡 Vulnerability: The admin login endpoint (`requireOperator` middleware using Basic Authentication) lacked rate limiting, allowing infinite brute-force attempts on the `ADMIN_USERNAME` and `ADMIN_PASSWORD`.
🎯 Impact: Attackers could brute-force the operator credentials without being blocked, potentially gaining full administrative access to the platform.
🔧 Fix: Implemented an in-memory sliding window rate limiter for the `requireOperator` middleware. It tracks failed authentication attempts by IP address, limits them to 5 failures per 15 minutes, safely evicts old entries to prevent memory exhaustion (DoS), and clears the history upon successful login.
✅ Verification: `bun run test` verified that rate limiting and standard basic authentication behavior functions correctly.
