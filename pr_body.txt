💡 What:
Wrapped `StatCard` and `UsageBar` in `frontend/src/pages/Dashboard.tsx` with `React.memo()`.

🎯 Why:
To prevent unnecessary re-renders of these pure presentational components when unrelated state in the parent `Dashboard` component (such as the `managing` loading state for the portal session transition) changes.

📊 Impact:
Reduces unnecessary virtual DOM diffing and re-renders during state transitions, improving rendering performance on the Dashboard.

🔬 Measurement:
Run the frontend development server and open React DevTools with "Highlight updates when components render" enabled. Toggle the portal session request (or simulate state changes) and observe that `StatCard` and `UsageBar` do not highlight/re-render.
