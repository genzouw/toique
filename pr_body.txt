💡 What: Wrapped `EmptyState` and `ErrorAlert` pure presentational components with `React.memo()`.
🎯 Why: These components are frequently used inside lists, dashboards, and tables. When parent components change their local state (e.g., toggling loading spinners) or refetch data due to network state changes, these pure UI components do not need to re-render if their props remain unchanged, which would otherwise blindly re-render these static leaf components.
📊 Impact: Reduces React virtual DOM diffing overhead by skipping renders for these components, eliminating redundant re-renders of static fallback components across the application, especially in `Forms`, `Channels`, and `Messages` views where loading state transitions frequently occur.
🔬 Measurement: Can be verified using the React Developer Tools Profiler. Observe that `EmptyState` and `ErrorAlert` no longer highlight/re-render when parent states (like loading spinners in Dashboard) update but their passed props do not change.
