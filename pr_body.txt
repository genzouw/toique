最新の生成AIツールとベストプラクティスを導入し、当リポジトリのAI自動化パイプラインをさらに最適化・ブラッシュアップしました。

## 💡 概要

1. **AI RAG 用の高精度 Web 検索の導入 (Exa API)**
   - `ai-web-search/action.yml` において、従来の DuckDuckGo / Tavily API に加えて、開発者向けの高品質な検索（Neural Search）を提供する `Exa API` (`exa_py`) を導入しました。
2. **AI PR Code Review の品質向上 (Reviewdog 連携)**
   - `ai-pr-review.yml` を改修し、GitHub Models のプロンプトからファイルパス (`file`) と行番号 (`line`) を出力させ、それを `rdjson` フォーマットに変換するステップを追加しました。
   - `reviewdog/action-reviewdog` を用いて、巨大な単一コメントではなく、PRの差分（Files changed）に対してインラインでピンポイントに指摘コメントが投稿されるように改善しました。
3. **継続的QAの実験的導入 (Agentic Workflows)**
   - GitHub Nextが提唱する自然言語でのワークフロー定義（Agentic Workflows）の概念に基づき、テストの改善やエッジケースの発見を自動化する `ai-continuous-qa-agent.md` を追加しました。

## ⚠️ マージ前の手動事前作業 (重要)

AI の高精度 Web 検索（Exa API）を利用するために、管理者は以下の手順で設定を行う必要があります。この手順は `.github/AI_AUTOMATION_SETUP.md` にも追記されています。

1. [Exa](https://exa.ai/) の公式サイトで無料アカウントを作成し、API キーを取得します。
2. GitHub リポジトリの **Settings → Secrets and variables → Actions** を開きます。
3. **New repository secret** をクリックし、名前を `EXA_API_KEY` とし、取得した API キーを値として保存します。

（※APIキーが存在しない場合は安全にフォールバックされるため、すぐに壊れることはありませんが、品質向上のために設定を強く推奨します）
