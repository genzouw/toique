## 2025-01-31 - Memoize array filtering to prevent O(N) recalculations\n**Learning:** The frontend React codebase has instances where array filtering or mapping operations (like `rows.filter(...)` or `INDUSTRIES.filter(...)`) are performed directly within the render body without memoization. When combined with other state changes, this causes unnecessary recalculation on every render, which is a common React performance anti-pattern. The codebase explicitly warns about this in memory: "To prevent unnecessary CPU overhead during React re-renders, wrap array filtering or mapping operations (e.g., rows.filter(...)) in useMemo within frontend components."\n**Action:** Always wrap expensive or potentially large array operations like `.filter` or `.map` in `useMemo` in React functional components.
